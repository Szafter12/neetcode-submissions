## Key Takeaways & Workflow

- **No memorizing code:** If a pattern doesn't click after 20 minutes, review the concept, implement from intuition, and revisit it spaced out (SRS).
- **Benchmarking:** Every problem is analyzed beyond just getting an "Accepted" status:
  - Is the current approach minimal in extra memory allocation?
  - Can edge cases (null inputs, empty sequences, single-element collections) be handled naturally without branching?
